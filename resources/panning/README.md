# Archived panning artwork

This artwork belonged to the custom rock-and-wash minigame (updates 5-7).
Update 8 restores the original prospector animation and no longer loads or
packages this artwork. It remains here as source history for the previous work.

## Original creation

`creek-source.png` is new artwork generated with the built-in image-generation tool
on 2026-09-23. `creek.ppm` is the 320 x 112, 24-colour runtime bitmap, reduced with
nearest-neighbour sampling. It was copied to `panning-creek.ppm` beside the executable.
The animated pan, gravel, flakes, water, hands, controls and 5x7 lettering were drawn
as native pixels by the former `src/panning.cpp` and `src/pixel_art.h`.
No original game asset was changed. See `prompt.txt` for the generation prompt.
